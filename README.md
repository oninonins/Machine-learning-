## Tentang Mata Kuliah

Mata kuliah Machine Learning membahas konsep dan penerapan algoritma pembelajaran mesin, meliputi:

- Pengenalan Machine Learning
- Data preprocessing dan feature engineering
- Supervised learning (regresi & klasifikasi)
- Unsupervised learning (clustering & dimensional reduction)
- Evaluasi model
- Implementasi menggunakan Python dan library terkait (scikit-learn, pandas, numpy, dll.)


Repositori ini dibuat untuk keperluan pembelajaran.
